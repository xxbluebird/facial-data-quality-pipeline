# Facial Image Data Collection Consent Template

## Project

Facial Image Data Collection & Quality Validation Pipeline

## Purpose

The purpose of this project is to develop and demonstrate a workflow
for collecting and evaluating facial images for AI dataset preparation.

## Data Collected

The project may collect:

- Facial images
- Viewing angle
- Lighting condition
- Capture session information
- Technical image-quality measurements

## Participation

Participation is voluntary.

Participants should understand the purpose of the project before image
collection begins.

## Data Handling

Participants will be assigned a pseudonymous subject identifier.

Raw identifiable facial images will not be publicly released without
explicit permission.

## Public Repository

Source code, documentation, quality-control results, and non-identifiable
metadata may be published.

Identifiable facial images will remain excluded from the public repository
unless explicit authorization has been provided.

## Withdrawal

Participants may request withdrawal of their data.

Where applicable, the corresponding images and associated metadata will
be removed from the working dataset.
