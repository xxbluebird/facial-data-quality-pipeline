# Data Privacy and Handling

## Purpose

This project demonstrates a privacy-aware facial image data collection
and quality-validation workflow for AI dataset preparation.

The collected data are used only for development, testing, and
demonstration of the image quality-control pipeline.

## Purpose Limitation

Facial images collected for this project will only be used for the
purposes described in the project documentation.

Images will not be reused for unrelated purposes without additional
consent from the participant.

## Data Minimization

Only information required for image acquisition and quality validation
is collected.

The dataset does not require participant names, addresses, identification
numbers, or other unnecessary personal information.

## Subject Pseudonymization

Participants are represented using pseudonymous subject identifiers such as:

S001
S002
S003

Participant names are not stored in the main dataset metadata.

## Access to Identifiable Images

Raw identifiable facial images are stored locally and are not included
in the public GitHub repository.

Access to raw images is limited to the project researcher and authorized
participants when necessary.

## Retention

Facial images are retained only for the duration required for project
development and evaluation.

The retention period should be communicated to participants before data
collection.

## Withdrawal and Deletion

Participants may request withdrawal of their data from the project.

When withdrawal is requested, the corresponding facial images and
associated metadata will be removed from the working dataset where
applicable.

## Public Repository

The public repository contains:

- Source code
- Documentation
- Non-identifiable metadata examples
- Quality-control reports
- Aggregated results

Raw identifiable biometric images are intentionally excluded from the
public repository.

## Privacy Principles

The project is designed using privacy-aware data handling principles,
including informed consent, purpose limitation, data minimization,
pseudonymization, restricted access, and deletion procedures.

This project does not claim formal GDPR or CCPA compliance.
